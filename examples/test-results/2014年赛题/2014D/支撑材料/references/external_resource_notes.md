# IMA与外部资料检索记录

## 题型判断
2014D“储药柜的设计”属于离散优化/分组聚类/二维装箱容量估算问题，核心是：
- 竖向隔板间距类型最少与冗余最小之间的多目标折中；
- 横向隔板间距类型与平面冗余的多目标折中；
- 基于药品需求、药盒尺寸、槽长与柜体尺寸估算槽数和柜数。

## IMA检索
1. 检索“整数规划 储药柜 药盒 优化”：未命中特定同题资料，说明需从通用优化方法转化。
2. 在“规划模型/优化”目录检索“整数规划”：命中《整数规划.docx》《第02章 整数规划.pdf》《M05 整数规划.ppt》等资料。
3. 检索“多目标决策优化”：命中“多目标决策优化”目录。

## 转化为本题方法
- 问题1：以药盒宽度为一维覆盖对象，间距为按宽度升序构造的类别；在防侧翻/旋转条件下按有效宽度聚类，baseline为每个宽度一种类型。
- 问题2：使用一维动态规划求“给定类型数K时的最小总宽度冗余”，再用膝点/归一化综合评分选择合理K；baseline为K=1和K=所有不同宽度。
- 问题3：在问题2宽度分类基础上，对药盒高度用同类动态规划，目标为总平面冗余=宽度冗余×高度冗余；再用膝点选择横向隔板间距类型数。
- 问题4：每种药品所需槽数=ceil(日最大需求量 / floor(1500/药盒长度))；单柜可用宽高二维容量按问题2/3类型对应药槽宽高估算，结合启发式二维货架装箱计算最少柜数。
