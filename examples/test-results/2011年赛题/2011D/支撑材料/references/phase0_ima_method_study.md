# Phase 0：IMA知识库与同类方法学习记录

## 题型判断
2011D“天然肠衣搭配问题”要求在给定不同长度档原料数量下，按三类成品规格组装尽可能多的捆，并在捆数相同情况下优先生产最短长度更长的规格。该问题属于：

- 整数规划 / 多重背包 / 装箱切割类问题；
- 带规格降级使用规则的资源分配问题；
- 目标具有字典序优先级：总捆数最大，其次长规格捆数最大，再其次中规格捆数最大。

## 可借鉴方法

### 1. 整数规划
- 支持问题：变量为非负整数、资源数量有限、目标函数和约束可线性表达的问题。
- 适用条件：原料长度档离散，根数为整数，每捆长度和根数限制清楚。
- 借鉴点：用整数变量表示某种搭配模式使用次数，建立材料容量约束和目标函数。
- 风险：若只用聚合变量约束每类规格总根数/总长度，可能得到不能拆分成单捆的“伪可行解”。因此最终采用“可行单捆模式生成 + 整数规划主问题”。

### 2. 背包/装箱思想
- 支持问题：把不同长度物品装入容量约束接近固定值的箱/捆。
- 适用条件：每捆目标总长度 89m，允许误差 ±0.5m，根数允许少 1 根。
- 借鉴点：先枚举满足单捆规格的可行模式，再选择模式组合。
- 风险：朴素贪心会局部最优，且不易满足“长规格优先”的字典序规则。

### 3. 字典序优化
- 支持问题：多个目标有明确优先级。
- 适用条件：题目明确“成品捆数越多越好；捆数相同时，最短长度最长的成品越多越好”。
- 借鉴点：采用大权重目标 `100000*总捆数 + 1000*长规格 + 10*中规格 + 短规格`，保证优先级不被低层目标扰动。
- 风险：权重必须大于低优先级目标可能变化范围，否则可能破坏字典序。本文权重远大于最大可能捆数（约 194）。

## 转化为本文方案

- baseline：总长度上界 `floor(总长度/88.5)` 和简单贪心装捆，用作可行性上界/对照；
- 主模型：可行模式生成 + 整数规划主问题；
- 验证方案：检查每捆根数、总长度、原料使用不超过库存、字典序目标、剩余原料；
- 论文结构：问题分析 → 模型假设 → 模式生成模型 → 整数规划主模型 → 求解结果 → 可行性和敏感性分析。
